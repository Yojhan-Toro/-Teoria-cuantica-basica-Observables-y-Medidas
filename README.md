# Quantum Simulator

Este proyecto implementa un simulador cuántico que permite modelar un sistema con una partícula confinada a un conjunto discreto de posiciones en una línea. La implementación sigue las especificaciones del capítulo 4.1 y resuelve los problemas de los capítulos 4.3 y 4.4.

## Descripción

El sistema cuántico permite realizar las siguientes operaciones fundamentales:

1. **Probabilidad de encontrar la partícula** en una posición dada.
2. **Amplitud de transición** entre dos estados cuánticos definidos por vectores ket.
3. **Cálculo de la media y la varianza** de un observable a partir de una matriz hermitiana.
4. **Valores propios y probabilidad de transición** hacia los vectores propios del observable.
5. **Evolución del sistema cuántico** a lo largo del tiempo mediante una serie de matrices unitarias.
